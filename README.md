# منشئ السيرة الذاتية الاحترافية (ATS-Friendly)

موقع ويب بسيط من 4 ملفات فقط لإنشاء سيرة ذاتية احترافية متوافقة مع أنظمة تتبع المتقدمين (ATS)، مع معاينة مباشرة، تحميل بصيغة Word (`.docx`)، واستيراد بيانات من ملف سيرة موجود.

## ✨ المميزات
- واجهة عربية RTL نظيفة وسريعة.
- معاينة مباشرة للسيرة أثناء الكتابة.
- إضافة/حذف ديناميكي للخبرات والمؤهلات.
- تحميل السيرة بصيغة **Word (.docx)** بتنسيق نظيف خالٍ من الجداول والصور — متوافق 100% مع ATS.
- رفع سيرة ذاتية بصيغة `.docx` أو `.txt` أو `.json` لاستخراج البيانات تلقائياً.
- بدون أي إطار عمل — HTML/CSS/JS خام (مع JSZip من CDN لبناء ملف Word).

## 📁 ملفات المشروع
| الملف | الوصف |
|------|--------|
| `index.html` | الهيكل والواجهة |
| `style.css`  | التصميم والتنسيق |
| `script.js`  | المنطق والمعاينة والتصدير والاستيراد |
| `README.md`  | هذا الملف |

## 🚀 التشغيل
افتح `index.html` مباشرة في المتصفح — لا حاجة لخادم.

```bash
# اختياري: تشغيل عبر خادم محلي
python3 -m http.server 8000
```

## 🧠 كيف يعمل استيراد البيانات؟
- **JSON**: يقرأ الحقول مباشرة (`fullName`, `email`, `experience[]`, إلخ).
- **DOCX**: يستخرج النص من `word/document.xml` داخل الـ ZIP، ثم يحلل البريد والهاتف وLinkedIn والأقسام (الملخص، المهارات، اللغات).
- **TXT**: نفس آلية تحليل DOCX.

## 📝 لماذا متوافق مع ATS؟
- نص حقيقي بدون جداول أو صور أو أعمدة.
- عناوين أقسام واضحة (الخبرات / المؤهلات / المهارات).
- خط Calibri القياسي وهوامش طبيعية.
- بنية XML خطية يقرأها أي نظام ATS بسهولة.

## 📦 الاعتمادات
- [JSZip](https://stuk.github.io/jszip/) عبر CDN — لبناء وقراءة ملفات `.docx`.
